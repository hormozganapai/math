# 🎲 MathPlay — پلتفرم بازی‌های آموزشی ریاضی

MathPlay یک پلتفرم وب برای دانش‌آموزان دوره متوسطه اول ایران است که مفاهیم ریاضی
(احتمال، جبر، هندسه، آمار) را از طریق بازی‌های تعاملی و مرحله‌ای آموزش می‌دهد.

- بدون نیاز به Backend — فقط HTML5, CSS3, JavaScript خالص
- کاملاً قابل انتشار روی **GitHub Pages**
- معماری **Plugin-Based**: هر بازی یک ماژول مستقل است
- ذخیره‌سازی امتیاز و پیشرفت با `LocalStorage`
- رابط کاربری فارسی، راست‌چین و واکنش‌گرا (موبایل و دسکتاپ)

## 🧩 معماری افزونه‌ای (Plugin-Based)

هر بازی یک پوشه مستقل داخل `games/` است و شامل ۴ فایل ثابت می‌شود:

| فایل | وظیفه |
|---|---|
| `game.html` | صفحه مستقل بازی |
| `game.js` | منطق بازی |
| `style.css` | استایل اختصاصی بازی |
| `info.json` | متادیتای بازی برای نمایش در صفحه اصلی |

نمونه `info.json`:

```json
{
  "title": "بازی احتمال",
  "grade": "هفتم",
  "category": "احتمال",
  "description": "آموزش احتمال با بازی",
  "icon": "🎲",
  "url": "games/probability/game.html"
}
```

صفحه اصلی از طریق `js/game-loader.js` فایل `games.json` را می‌خواند (که فهرست
نام پوشه‌هاست)، سپس برای هر پوشه فایل `info.json` را واکشی کرده و کارت بازی
متناظر را می‌سازد.

### ➕ افزودن بازی جدید

۱. یک پوشه جدید در `games/` بساز، مثلاً `games/geometry/`
۲. چهار فایل `game.html`, `game.js`, `style.css`, `info.json` را داخل آن قرار بده
۳. نام پوشه را به آرایه `games` در فایل `games.json` اضافه کن:

```json
{
  "games": ["probability", "equation", "geometry"]
}
```

نیازی به تغییر `index.html` یا `app.js` نیست — کارت بازی جدید به‌صورت خودکار
در صفحه اصلی ظاهر می‌شود.

## 🎮 بازی‌های موجود

### ۱. دنیای احتمال 🎲
**دسته‌بندی:** احتمال

با پرتاب سکه و تاس، مفهوم احتمال را کشف کن و حدس‌هایت را با نتیجه واقعی آزمایش مقایسه کن.

### ۲. قهرمان معادله ⚔️
**دسته‌بندی:** جبر

معادله‌های یک مجهولی را حل کن، امتیاز بگیر و از سطح آسان تا سخت پیش برو.

### ۳. شهر اعداد صحیح 🏙️
**دسته‌بندی:** اعداد صحیح

یادگیری مفهومی اعداد مثبت و منفی با آسانسور

### ۴. سرزمین جبر 🏰
**دسته‌بندی:** جبر

قهرمان سرزمین جبر شو و جادوگر مجهول را با حل معما، ترازو، کارخانه و قطار شکست بده.

### ۵. مربع جادویی 🔮
**دسته‌بندی:** پازل ریاضی

اعداد را در مربع بچین تا مجموع هر سطر، ستون و قطر با هم برابر شود. از ۳×۳ تا ۵×۵ پیش برو!

### ۶. جنگل کسرها 🌳
**دسته‌بندی:** کسرها

یادگیری مفهومی کسرها با تقسیم، ساخت، مقایسه و عملیات در یک جنگل جادویی

### ۷. سرزمین هندسه 🏰
**دسته‌بندی:** هندسه

یادگیری مفهومی هندسه با ساخت شکل، اندازه‌گیری و حل چالش‌های هندسی

### ۸. دره اعداد صحیح 🏔️
**دسته‌بندی:** اعداد صحیح

یادگیری مفهومی اعداد صحیح با ماجراجویی در یک دره اسرارآمیز

### ۹. جزیره احتمال 🏝️
**دسته‌بندی:** احتمال

یادگیری مفهومی احتمال با آزمایش، پیش‌بینی و بازی در یک جزیره اسرارآمیز

### ۱۰. شهر آمار 🏙️
**دسته‌بندی:** آمار

یادگیری مفهومی آمار با جمع‌آوری، مرتب‌سازی، نمودار و تحلیل داده‌ها

### ۱۱. آزمایشگاه جبر 🧪
**دسته‌بندی:** جبر

یک محیط تعاملی برای حل معادلات جبری و ساده‌سازی عبارت‌ها. اعداد را جابجا کن و قوانین ریاضی را کشف کن!

### ۱۲. بازی ریاضی کِن‌کِن 🧩
**دسته‌بندی:** معما و منطق

با پر کردن جدول اعداد و رعایت قوانین ریاضی (جمع، تفریق، ضرب و تقسیم) پازل را حل کن.

### ۱۳. پازل کاکورو 🧩
**دسته‌بندی:** پازل ریاضی

اعداد ۱ تا ۹ را در خانه‌های خالی قرار بده تا مجموع آن‌ها با عدد نشان‌داده‌شده در سرنخ‌ها برابر شود. بدون تکرار عدد در یک ردیف یا ستون!

### ۱۴. بازی ریاضی تانگرام 🧩
**دسته‌بندی:** هندسه

حل معماهای هندسی با استفاده از ۷ قطعه تانگرام، آموزش اشکال، دوران و قرینه‌سازی.

### ۱۵. بازی ریاضی پنتومینو 🧩
**دسته‌بندی:** پازل ریاضی

پازل پنتومینو! ۱۲ شکل مختلف را بچرخانید و در صفحه قرار دهید تا یک مستطیل یا مربع کامل بسازید.

### ۱۶. بازی ریاضی اسپروتز 🌱
**دسته‌بندی:** توپولوژی و نظریه گراف

اسپروتز یک بازی جذاب توپولوژی است که با رسم خطوط بین نقطه‌ها و رعایت قوانین عدم تقاطع، به یادگیری گراف‌های مسطح کمک می‌کند.

### ۱۷. بازی ریاضی هِگز ⬡
**دسته‌بندی:** استراتژی و منطق

بازیکنان تلاش می‌کنند با ساختن یک مسیر پیوسته از مهره‌های خود، دو ضلع مقابل تخته را به هم متصل کنند.

### ۱۸. بازی ریاضی چامپ 🍫
**دسته‌بندی:** پازل ریاضی

تخته شکلات سمی! مهره‌ها را بخور تا آخرین قطعه سمی به حریف برسد. یادگیری استراتژی‌های برد در بازی‌های ترکیبی.

### ۱۹. برج هانوی 🗼
**دسته‌بندی:** الگوریتم و استدلال

پازل کلاسیک برج هانوی را حل کن و با الگوریتم‌های بازگشتی، شمارش باینری و توان‌های دو آشنا شو. کمترین تعداد حرکت ممکن را پیدا کن!

### ۲۰. بازی ریاضی نیم 🕹️
**دسته‌بندی:** معما و منطق

با برداشتن آیتم‌ها از دسته‌ها، حریف را شکست دهید. بازی استراتژیک با تحلیل ریاضی.

### ۲۱. پازل ۱۵ 🧩
**دسته‌بندی:** منطق، کلاسیک، اعداد

اعداد را به ترتیب از چپ به راست مرتب کنید. این نسخه از بازی همیشه قابل حل است!

### ۲۲. مسئله ۸ وزیر ♛
**دسته‌بندی:** جبر

چگونه ۸ وزیر را روی صفحه شطرنج قرار دهیم که هیچ‌کدام یکدیگر را تهدید نکنند؟ با الگوریتم پس‌گرد (Backtracking) آشنا شوید.

### ۲۳. پل‌های کونیگسبرگ 🌉
**دسته‌بندی:** نظریه گراف

حل معمای تاریخی پل‌های کونیگسبرگ و مسیرهای اویلری با رسم یک‌خطی

## 💾 ذخیره‌سازی اطلاعات

تمام پیشرفت بازیکن در `localStorage` مرورگر (کلید `mathplay_stats`) ذخیره
می‌شود و شامل موارد زیر است:

- بالاترین امتیاز هر بازی (`highScore`)
- تعداد دفعات بازی هر بازی (`timesPlayed`)
- آخرین سطح/مرحله انجام‌شده (`lastLevel`)

این اطلاعات در هدر صفحه اصلی و روی کارت‌های بازی (برچسب رکورد) نمایش داده
می‌شود.

## 🖥️ اجرا روی کامپیوتر شخصی

چون پروژه بدون Backend است، از فایل `fetch` برای خواندن `games.json` و
`info.json` استفاده می‌شود؛ به همین دلیل باز کردن مستقیم `index.html` با
دابل‌کلیک (پروتکل `file://`) در برخی مرورگرها به دلیل محدودیت CORS کار
نمی‌کند. بهترین روش اجرای محلی، بالا آوردن یک سرور استاتیک ساده است:

**با Python (از قبل نصب است در اکثر سیستم‌ها):**
```bash
cd MathPlay
python -m http.server 8000
```
سپس در مرورگر به آدرس زیر برو:
```
http://localhost:8000
```

**یا با افزونه VS Code:**
پروژه را در VS Code باز کن، افزونه **Live Server** را نصب کن و روی
`index.html` کلیک راست بزن و گزینه «Open with Live Server» را انتخاب کن.

**یا با Node.js:**
```bash
npx serve MathPlay
```

## 🚀 انتشار روی GitHub Pages

۱. یک ریپازیتوری جدید در GitHub بساز (مثلاً `mathplay`).

۲. محتوای پوشه `MathPlay/` را به ریپازیتوری push کن:
```bash
cd MathPlay
git init
git add .
git commit -m "اولین نسخه MathPlay"
git branch -M main
git remote add origin https://github.com/<username>/mathplay.git
git push -u origin main
```

۳. وارد تنظیمات ریپازیتوری شو: **Settings → Pages**

۴. در بخش **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` و پوشه `/ (root)`
   - روی **Save** کلیک کن

۵. بعد از چند دقیقه، سایت در آدرس زیر در دسترس خواهد بود:
```
https://<username>.github.io/mathplay/
```

> نکته: چون پروژه از مسیرهای نسبی (`games/...`, `css/...`) استفاده می‌کند،
> نیازی به تنظیم `base path` اضافه نیست و روی GitHub Pages به‌درستی کار
> می‌کند.
