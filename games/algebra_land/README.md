# 🏰 سرزمین جبر (Algebra Land)

بازی آموزشی جبر برای دانش‌آموزان پایه هفتم — قهرمانی که باید با عبور از پنج
منطقه (شهر ترازو، کارخانه، ایستگاه معادله، جزیره مجهول و قلعه جادوگر جبر)
مفهوم عبارت جبری و معادله یک مجهولی را یاد بگیرد.

بازی کاملاً **مستقل** است: فقط با باز کردن `game.html` اجرا می‌شود، بدون نیاز
به سرور، Backend یا هیچ کتابخانه خارجی.

## 📁 ساختار فایل‌ها

```
games/algebra_land/
├── game.html            اسکلت HTML و بارگذاری اسکریپت‌ها
├── style.css             استایل کامل (روشن/تاریک)
├── game.js                کنترلر اصلی بازی (AlgebraLandGame)
├── QuestionGenerator.js   تولید تصادفی سؤال هر منطقه + ابزارهای مشترک
├── ScoreManager.js        امتیاز، ستاره، مدال
├── UI.js                  رندر DOM هر ویجت
├── Storage.js              ذخیره‌سازی LocalStorage
├── SoundManager.js         صداهای بازی با Web Audio API
├── Animation.js            ذرات نور، کانفتی، ابر، ترنزیشن صفحه‌ها
├── info.json                متادیتای بازی برای MathPlay
└── assets/
    ├── images/            (رزرو برای گرافیک سفارشی آینده)
    └── sounds/             (رزرو برای فایل صوتی واقعی آینده)
```

### چرا هیچ فایل صوتی/تصویری واقعی نیست؟
طبق الزام «بدون هیچ وابستگی خارجی»، تمام صداها با **Web Audio API** به‌صورت
برنامه‌ریزی‌شده تولید می‌شوند (`SoundManager.js`) و تمام گرافیک‌ها با
HTML/CSS/Emoji ساخته شده‌اند.

### چرا از import/export ماژول استفاده نشده؟
باز کردن مستقیم `game.html` با پروتکل `file://` در برخی مرورگرها اسکریپت‌های
ES Module را به‌دلیل سیاست CORS مسدود می‌کند. برای اجرای واقعاً مستقل، هر
فایل یک کلاس ES6 با نام یکتا تعریف می‌کند و فایل‌ها با تگ `<script>` معمولی
و به‌ترتیب وابستگی بارگذاری می‌شوند:

```html
<script src="Storage.js"></script>
<script src="ScoreManager.js"></script>
<script src="SoundManager.js"></script>
<script src="Animation.js"></script>
<script src="QuestionGenerator.js"></script>
<script src="UI.js"></script>
<script src="game.js"></script>
```

## 🗺️ نقشه و مناطق بازی

| # | منطقه | مفهوم آموزشی | نوع تعامل |
|---|---|---|---|
| ۱ | ⚖ شهر ترازو | حفظ تعادل معادله | Drag & Drop بلوک |
| ۲ | 🏭 کارخانه عبارت‌های جبری | عبارت جبری به‌عنوان زنجیره عملیات | ورودی/خروجی عددی |
| ۳ | 🚂 ایستگاه معادله | حل معادله ساده | پیدا کردن عدد گم‌شده |
| ۴ | 🏴 جزیره مجهول | معادله ax+b=c | حل معادله |
| ۵ | 🏰 قلعه جادوگر جبر | مبارزه نهایی (هر سه فرم معادله مخلوط) | حل سریع و پیاپی |

هر منطقه فقط زمانی باز می‌شود که منطقه قبلی تمام شده باشد. قبل از شروع هر
منطقه، آموزش کوتاهی نمایش داده می‌شود (مفهوم → بازی → تمرین → آزمون).

بازی یک سطح سختی ثابت و متعادل دارد (بدون انتخاب آسان/متوسط/سخت جداگانه)؛
چالش با پیشروی طبیعی در نقشه بالا می‌رود و مبارزه نهایی هر سه فرم معادله
(`x+a=b`، `ax+b=c`، `ax+b=cx+d`) را به‌صورت تصادفی با هم ترکیب می‌کند.

### 🏗️ افزودن منطقه جدید
1. یک متد تولید سؤال جدید در `QuestionGenerator.js` اضافه کنید.
2. در صورت نیاز، یک متد رندر جدید در `UI.js` اضافه کنید.
3. یک آبجکت جدید به آرایه `STAGES` در `game.js` اضافه کنید.

## ⭐ سیستم امتیاز و مدال

- پاسخ صحیح: ۱۰ امتیاز؛ پاسخ سریع (کمتر از ۸ ثانیه): ۵+ امتیاز اضافه
- ستاره هر منطقه: بیش از ۹۰٪ = ۳ ستاره، ۷۰–۹۰٪ = ۲ ستاره، کمتر = ۱ ستاره

| مدال | شرط دریافت |
|---|---|
| 🥉 شاگرد جبر | اتمام «شهر ترازو» (اولین منطقه) |
| 🥈 استاد معادله | اتمام «ایستگاه معادله» |
| 🥇 قهرمان سرزمین جبر | اتمام کامل بازی با حداقل ۸۰٪ پاسخ صحیح |
| 👑 ناجی سرزمین | اتمام کامل بازی بدون حتی یک پاسخ غلط |


## 💾 ذخیره‌سازی (کلید: `algebra_land_save`)

بهترین امتیاز، آخرین مرحله، مدال‌ها، زمان کل بازی، تعداد پاسخ صحیح/غلط، تم و
وضعیت صدا.

## 🖥️ اجرای بازی

فایل `game.html` را مستقیماً در مرورگر باز کنید — نیازی به سرور نیست. برای
اجرا داخل سایت MathPlay، از صفحه اصلی روی کارت «سرزمین جبر» کلیک کنید.

## ➕ افزودن به سایت MathPlay

1. پوشه `games/algebra_land/` را داخل `games/` پروژه MathPlay قرار دهید.
2. نام `"algebra_land"` را به آرایه `games` در `games.json` اضافه کنید.

هیچ تغییر دیگری لازم نیست.
